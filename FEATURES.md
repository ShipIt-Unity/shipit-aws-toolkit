# ShipIt AWS Toolkit — feature overview

This brief overview describes the product at a marketing level. It does not disclose source code, implementation details, or complete technical documentation.

- **Connected game services:** bring selected cloud capabilities into a Unity game project.
- **Player workflows:** support common online account, data, and progression needs.
- **Project operations:** manage service configuration and development tasks from a Unity-focused workflow.
- **Deployment choices:** connect to cloud resources in an AWS account that you operate.

You bring and operate the cloud account. This overview does not list the supported service matrix or compatibility range; see the website and product documentation for current scope and requirements.
